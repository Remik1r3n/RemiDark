# RemiDark Theme
RemiDark 主题是基于 [Pinghsu](https://github.com/chakhsu/pinghsu) 的一款 Typecho 主题，采用了全 AMOLED 的深色设计。

RemiDark 主题希望做到极致的简约——最好比 Pinghsu 再更加简约。同时，也做了很多反映我个人审美的更改。

**注意**：本主题以*自用*为主，维护较少。

## 相比 Pinghsu 的更改
- 完全使用 AMOLED 深色设计，**没有浅色模式支持**，且目前没有计划支持。
- 全局强调色改为 #066EAC 蓝色。
- 增大字体以提升可读性。
- 更改了很多文案。现在文案更加普世、专业。
- 增加评论区的 Cloudflare Turnstile 支持。
- 增加萌ICP备案支持。
- 更改了其他部分样式以符合个人审美。
